**입력 범용화 업데이트:** [다양한 열 이름·단위·Excel/구분자 사용법](../UNIVERSAL_INPUT_ko.md). 최소 3열 양식도 추가했습니다. 기존 양식은 그대로 사용할 수 있습니다.

**2026-11-06 전수 검증:** [검증 결과](../../validation_20261106/report_ko.md)를 확인하세요. 읽기 성공과 ECM 품질 통과는 다릅니다. Wuppertal HPPC는 현재 검출 조건에서 23구간 모두 결과가 없으며, 다른 자료도 review를 구분해야 합니다. CSV 읽기와 HPPC 화면 갱신 문제를 수정했으므로 앱을 다시 실행하세요.

## 양식 선택

원본에 있는 임피던스 표기와 같은 양식 **하나**를 복사해 사용하세요.

| CSV | 필요한 측정 열 | 단위 |
| --- | --- | --- |
| `EIS_signed_Im_template.csv` | `frequency_hz`, `z_real_ohm`, `z_imag_ohm` | Hz, Ω, Ω |
| `EIS_negative_Im_template.csv` | `frequency_hz`, `z_real_ohm`, `neg_im_z_ohm` | Hz, Ω, Ω |
| `EIS_magnitude_phase_template.csv` | `frequency_hz`, `magnitude_ohm`, `phase_deg` | Hz, Ω, 도(°) |

`z_imag_ohm`은 **부호 있는 Im(Z)**, `neg_im_z_ohm`은 **−Im(Z)**입니다. 원본 정의를 확인해 고르고 숫자의 부호는 그대로 유지하세요. 허수부에 절댓값을 취하지 마세요. 두 허수부 열이나 서로 다른 같은 뜻의 열을 동시에 넣으면 자동 연결이 모호해질 수 있습니다.

원본이 mΩ이면 Ω으로 변환한 뒤 Ω 열에 넣으세요: **Ω = mΩ ÷ 1000**. 숫자를 바꾸지 않고 단위 이름만 Ω으로 바꾸면 안 됩니다. 단위를 모르면 확인할 때까지 임의로 채우지 마세요. 위상은 원본 부호를 유지한 도 단위입니다. 라디안이면 도로 정확히 변환하거나 앱의 수동 연결·단위 설정을 사용하세요.

## 한 행과 한 측정의 기준

- 한 행 = 한 주파수에서 측정한 임피던스 한 점.
- 한 스윕(주파수를 바꾸어 측정한 EIS 1회)의 모든 행은 **같은 `spectrum_id`**를 사용합니다. 다음 스윕·반복 측정은 다른 ID를 사용합니다.
- `source_id`는 자료 출처, `cell_id`는 셀, `test_id`는 시험을 구분합니다. 원본 ID가 있으면 그대로 사용하세요. ID가 없는 경우 출처를 구분하는 이름을 정할 수 있으며, 이는 측정값을 만드는 일이 아닙니다.
- ID를 사용한다면 모든 측정 행에 채웁니다. 선택 ID 열 전체가 빈 경우에는 파일 단위 구분을 사용하지만, 일부 행만 비어 있으면 보류됩니다. ID가 일부 행에만 비어 있으면 입력 검사가 막힙니다. 전체 공란은 파일 단위 구분을 사용합니다. 여러 스윕을 합친 파일의 `spectrum_id`는 삭제하지 마세요.

다른 셀·스윕의 점을 섞거나 반복 측정을 평균내지 마세요. 현재 피팅은 스윕마다 **서로 다른 유효 주파수점 10개 이상**이 필요합니다. 주파수는 0보다 커야 하고 필수 측정값에 빈칸·문자가 없어야 합니다. 같은 스윕의 SOC·시험 온도·사이클·SOH는 같은 조건이어야 합니다. 센서 온도 변화 등을 임의로 평균내어 맞추지 말고 별도 원본 열로 보존하거나 조건 정보를 확인하세요.

## 선택 조건 열

| 열 | 넣을 내용 |
| --- | --- |
| `soc_pct` | 확인된 SOC, 0~100% |
| `temperature_C` | 확인된 시험 온도, 섭씨 °C |
| `cycle_number` | 원본 사이클 번호 |
| `soh_pct` | 정의·출처가 확인된 SOH, 0~100% |

조건이 확인되면 해당 스윕의 각 행에 같은 값을 넣습니다. 모르면 빈칸으로 두세요. 0~1 비율을 그대로 `%` 열에 넣지 마세요. 없는 조건·파라미터를 추정해서 추가하지 마세요. 명목 시험 조건과 센서 실측값도 구분해 사용하세요.

## 저장하고 모델에서 읽기

1. Excel 등에서 CSV를 복사해 열고 **첫 줄 열 이름 아래부터** 실제 측정값을 넣습니다. 열 이름은 유지합니다.
2. 행을 필요한 만큼 늘리고, 사용하지 않은 빈 행은 삭제합니다. 설명·단위만 적은 추가 행, 병합 셀은 넣지 않습니다.
3. **CSV UTF-8(쉼표로 분리)**로 저장합니다. 숫자는 소수점 `.`을 사용하고 숫자 칸에 Ω·Hz 등을 함께 쓰지 않습니다.
4. 앱에서 **파일 추가**로 열고, 데이터 종류는 **EIS**를 선택합니다.
5. **상세 설정 · 열 연결**에서 주파수와 임피던스가 연결됐는지 확인하고, **단위·추가 정보**에서 단위·허수부 부호를 확인합니다. 위 양식은 정확한 열 이름으로 자동 연결하도록 만들었습니다.
6. 아래 진단을 확인한 뒤 **1RC · 2RC 피팅 및 오차 비교**를 누릅니다.

2D는 X조건과 ECM 파라미터 값만 있으면 표시할 수 있습니다. 3D는 X·Y 두 조건과 ECM 값이 모두 필요합니다. 파일이 읽혀도 회로가 잘 맞는지는 잔차·오차·적합 상태로 따로 확인해야 합니다. Rs·Rct·Cdl 등 피팅 결과를 이 측정 양식의 입력값으로 대신 넣지 마세요.

실제 측정값을 채워 둔 파일은 [filled_real_data/EIS/](../filled_real_data/EIS/)에 있습니다. [자료별 출처·설정 안내](../filled_real_data/README_ko.md)를 먼저 확인하세요. 이 폴더의 CSV는 빈 양식으로 유지합니다.
