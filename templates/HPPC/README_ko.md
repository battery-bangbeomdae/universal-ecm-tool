# HPPC 데이터 입력 방법

**입력 범용화 업데이트:** [다양한 열 이름·단위·Excel/구분자 사용법](../UNIVERSAL_INPUT_ko.md). 최소 3열 양식도 추가했습니다. 기존 양식은 그대로 사용할 수 있습니다.

**2026-11-06 전수 검증:** [검증 결과](../../validation_20261106/report_ko.md)를 확인하세요. 읽기 성공과 ECM 품질 통과는 다릅니다. Wuppertal HPPC는 현재 검출 조건에서 23구간 모두 결과가 없으며, 다른 자료도 review를 구분해야 합니다. CSV 읽기와 HPPC 화면 갱신 문제를 수정했으므로 앱을 다시 실행하세요.

`HPPC_template.csv`를 복사해 실제 시간·전류·전압 기록을 채우세요. 한 행은 **같은 시점에 측정한 값 한 묶음**입니다.

## 필수 측정 열

| 열 이름 | 값 | 단위 |
| --- | --- | --- |
| `time_s` | 원본 경과 시간 | 초(s) |
| `current_A` | 충전/방전 부호를 유지한 전류 | A |
| `voltage_V` | 단자 전압 | V |

원본이 mA이면 열 이름을 **`current_mA`**로 바꾸고 원본 숫자를 유지해도 됩니다. mV는 **`voltage_mV`**, ms는 **`time_ms`**로 사용할 수 있습니다. 같은 뜻의 A/mA 열을 동시에 넣지 마세요. 숫자를 변환한다면 A=mA÷1000, V=mV÷1000, s=ms÷1000입니다.

전류 부호는 숫자만 보고 추정하지 말고 시험기 설명으로 확인하세요. 앱에서 **충전할 때 +** 또는 **방전할 때 +**를 반드시 선택합니다. 기존 D014 Bio-Logic HPPC 자료는 **충전할 때 +**입니다. 다른 자료에 이 부호를 그대로 적용하지 마세요.

## 식별자와 선택 조건

| 열 | 넣을 내용 |
| --- | --- |
| `source_id` | 자료 출처 구분 |
| `cell_id` | 셀 구분 |
| `test_id` | 연속 시험 구분; 같은 시험의 모든 행에 같은 ID |
| `soc_pct` | 확인된 SOC, 0~100%; 모르면 빈칸 |
| `temperature_C` | 확인된 온도, 섭씨 °C; 모르면 빈칸 |
| `cycle_number` | 원본 사이클 번호; 모르면 빈칸 |
| `soh_pct` | 정의·출처가 확인된 SOH, 0~100%; 모르면 빈칸 |

원본 식별자가 있으면 그대로 사용하세요. ID를 사용한다면 모든 측정 행에 채웁니다. 선택 ID 열 전체가 빈 경우에는 파일 단위 구분을 사용하지만, 일부 행만 비어 있으면 보류됩니다. 한 셀·한 시험이고 쓰지 않을 ID 열은 전체를 삭제할 수 있습니다. 여러 셀·독립 시험을 합치면 구분 ID가 필요합니다. 시간이 다시 시작하는 독립 시험은 반드시 다른 `test_id`를 사용하세요.

조건은 확인된 값만 넣습니다. 현재 도구의 펄스 결과 조건값은 **펄스 시작 행**을 기준으로 가져오므로 그 행의 조건이 해당 펄스에 맞는지 확인하세요. SOC를 모르면 임의로 0·50·100을 넣거나 적산하여 측정값처럼 쓰지 마세요. 조건값이 없어도 신호가 충분하면 국소 피팅을 시도할 수 있으나, 없는 조건의 축은 사용할 수 없습니다.

## 휴지·펄스·회복 구간 유지

**펄스 전 휴지 → 일정 전류 펄스 → 펄스 후 회복** 구간을 함께 넣으세요. 한 시험 안에서 시간은 중복 없이 계속 증가해야 하고, 필수 측정값은 모두 유한한 숫자여야 합니다. 시간 정렬·중복 삭제·보간·평활을 임의로 해서 맞추지 마세요.

현재 검출기의 최소 조건은 시험 신호 15점 이상이며, 피팅 대상 펄스는 앞 휴지 5점 이상·펄스 6점 이상·뒤 회복 5점 이상이어야 합니다. 실제 후보 펄스에는 최소 16점이 필요하다는 뜻이며, 이 숫자만 채웠다고 충분한 시험은 아닙니다. 샘플링과 휴지·회복 시간은 식별하려는 시정수를 관측할 만큼 충분해야 합니다. 너무 짧은 펄스나 전류가 크게 변하는 구간은 건너뛰거나 주의로 표시될 수 있습니다.

펄스 앞뒤를 잘라내거나 서로 다른 시간의 전압·전류를 붙이지 마세요. DCIR 숫자 하나나 일반 주행 기록만으로 현재 HPPC 피팅을 대신할 수 없습니다. EIS 주파수/임피던스 열은 같은 파일에 섞지 마세요.

## 저장하고 모델에서 읽기

1. 첫 줄 열 이름은 유지하고 두 번째 줄부터 실제 측정값을 넣습니다. 필요하면 행을 늘리고 사용하지 않은 빈 행은 삭제합니다.
2. 설명·단위만 적은 추가 행, 병합 셀은 넣지 않습니다. 숫자는 소수점 `.`을 사용하고 숫자 칸에 A·V·s 등의 글자를 함께 쓰지 않습니다.
3. **CSV UTF-8(쉼표로 분리)**로 저장합니다. 원본은 따로 보관합니다.
4. 앱의 **파일 추가**로 열고 **HPPC**, 정확한 **전류 부호**를 선택합니다.
5. **상세 설정 · 열 연결**에서 시간·전류·전압 연결을 확인하고 **단위·추가 정보**에서 단위를 확인합니다.
6. 주 화면 아래 진단을 확인하고 **1RC · 2RC 피팅 및 오차 비교**를 누릅니다.

2D는 X조건과 ECM 파라미터 값, 3D는 두 조건과 ECM 값이 필요합니다. R0·R1·C1 등은 측정 입력이 아닌 피팅 출력입니다. 국소 기준전압은 자동으로 평형 OCV가 되는 값이 아니며, 결과를 BMS 검증 완료로 취급하지 마세요.

실제 측정값을 채워 둔 파일은 [filled_real_data/HPPC/](../filled_real_data/HPPC/)에 있습니다. [자료별 출처·설정 안내](../filled_real_data/README_ko.md)를 먼저 확인하세요. 이 폴더의 CSV는 빈 양식으로 유지합니다.
