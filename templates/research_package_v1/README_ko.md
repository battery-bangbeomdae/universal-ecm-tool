# 실험별 ECM 표준 패키지 v1.0

이 폴더는 복사해서 채우는 빈 템플릿입니다. CSV에는 헤더만 있으며 가상 측정값은 없습니다. 한 연구마다 복사하고 experiments 아래에 실제 실험 폴더를 만드세요. EIS/HPPC 예시 폴더 이름은 바꾸고 사용하지 않는 빈 예시 폴더는 배포본에서 제외하세요.

## 현재 도구와 연결

현재 수정 대상은 ECM/YJ/Universal_ECM_Tool_Analysis_part이며 launch_universal_ecm.m으로 실행합니다. 이 패키지의 signals.csv와 measurements.csv는 현재 읽기·조건표 연결 규칙에 맞는 열을 사용합니다. 앱에서 실험의 signals.csv를 표준 입력으로 열고 measurements.csv를 해당 신호의 조건표로 추가하세요. EIS 또는 HPPC를 명시적으로 선택하고 자료 확인 후 피팅 실행을 누르세요. HPPC 표준은 충전 양수이므로 도구에서도 charge_positive를 확인하세요.

manifest.csv는 패키지 관리 규격입니다. 현재 앱에 manifest 기반 자동 패키지 연결 기능은 없습니다. 폴더 가져오기가 measurements.csv나 cells.csv를 자동 연결한다고 가정하지 마세요. 서로 다른 실험의 조건표는 해당 실험 신호에 연결하세요. 여러 실험의 조건표를 합칠 때는 네 식별자 조합의 유일성을 먼저 검사하세요.

cells.csv는 고정 정보의 정본입니다. 현재 앱이 이를 자동 조인하지 않으므로 변환 스크립트가 cells.csv를 cell_id로 연결하여 measurements.csv의 cell_model/cathode_family/cathode_composition/cell_format에 복사합니다. cell_model은 확인된 모델 문자열, cell_model_id는 관리용 모델 키입니다.

## 식별자와 묶음

source_id는 연구, cell_id는 개별 물리 셀, test_id는 실험/시험 ID입니다. measurement_id는 연구 내 유일한 개별 측정 ID이며 spectrum_id에도 같은 값을 넣습니다. HPPC도 동일하게 spectrum_id를 채웁니다. 현재 도구의 조건 연결은 source_id/cell_id/test_id/spectrum_id를 사용하므로 measurement_id만 채우면 안 됩니다. 같은 측정의 모든 신호 행에서 네 ID가 같아야 하고 조건표는 그 조합당 정확히 한 행이어야 합니다. point_index는 측정마다 1부터 증가합니다.

한 실험 폴더에 여러 SOC·사이클·셀의 측정을 함께 보관할 수 있습니다. EIS는 한 스펙트럼, HPPC는 앞 휴지·펄스·뒤 회복을 포함한 한 구간을 한 측정으로 만드세요. 반복 측정은 별도 ID로 보존하며 평균하지 않습니다. 서로 다른 실험 종류가 한 원본에 있으면 같은 연구 안에서 EIS/HPPC 실험 폴더로 나누고 출처를 연결하세요.

## 신호와 단위

EIS: frequency_hz [Hz], z_real_ohm [Ω], z_imag_ohm [부호 있는 Im(Z), Ω]. 크기/위상 원본은 Re=|Z|cos(phase), Im=|Z|sin(phase)로 계산하고 위상 단위를 변환 규칙에 기록합니다. −Im 원본은 부호를 반전합니다.

HPPC: time_s [s], current_A [A, 충전 양수], voltage_V [V]. 시간 원점은 측정 시작 0으로 이동할 수 있지만 원본 시각·오프셋을 provenance에 보존합니다. 전류 부호는 원본 설명이나 확실한 시험 근거로 확인합니다. 시간은 측정 안에서 엄격히 증가해야 합니다.

피팅용 양수 Im 제외는 도구의 정책입니다. 가공본에서는 해당 점도 보존하고 출처를 남깁니다. 보간·평활화·평균·임의 이상점 삭제를 기본 수행하지 않습니다. 결측 신호·시간 중복·역전은 조용히 수정하지 말고 검토 대상으로 기록하세요.

## 조건과 용량

SOC/SOH는 %, 온도는 °C, 사이클은 비음수 정수, 용량은 Ah입니다. 조건은 측정별이며 HPPC는 펄스 시작 기준입니다. 설정 온도와 실측 온도, 명목 SOC와 계산 SOC를 *_basis로 구분합니다. 시험 중 변화하는 값은 신호에 선택 열로 보존할 수 있으나 조건표에는 기준 시점을 명시하세요. 신호와 조건표에 같은 이름의 조건을 넣는 경우 값이 충돌하지 않아야 합니다.

미확인 숫자는 빈칸으로 두고 0으로 대체하지 않습니다. 없는 조건 때문에 유효 신호를 버리지 않습니다. 온도·SOC·SOH·사이클·용량을 추정으로 채우지 않습니다. 진단/RPT 번호와 프로토콜 스텝은 열화 사이클 수가 아닙니다.

초기·현재 용량은 같은 물리 셀의 실측값입니다. 용량 기준 SOH=100×현재/초기. 서로 비교 가능한 용량 시험의 온도·전류·전압 범위와 측정 시점을 근거로 기록하세요. 공칭 용량은 cells.csv에 별도로 보관하며 초기 실측 용량으로 대체하지 않습니다. 원본 SOH와 새 용량비가 다르면 덮어쓰지 말고 근거와 차이를 검토하세요. 100% 초과 비율을 임의 절삭하지 않습니다.

## 출처 행 번호

provenance의 output 행 번호는 CSV 헤더를 제외한 1-based 데이터 행입니다. 원본 행 번호는 CSV/Excel의 실제 물리 행(헤더 포함)이며 MAT는 해당 배열의 1-based 행 인덱스입니다. 여러 파일·불연속 구간에서 왔으면 대응 구간별로 여러 행을 작성하세요. 비연속 열/구간의 처리와 원래 시간 오프셋은 conversion 규칙에 기록하세요. 원본 해시는 실제 읽은 파일에서 계산하고 만들어내지 않습니다.

변환 지시는 LLM_CONVERSION_INSTRUCTIONS_ko.md, 열 정의는 schema.json, 검증 항목은 VALIDATION_CHECKLIST_ko.md를 사용하세요. 기존 team_data_20261106은 자동으로 이 규격으로 재변환되지 않습니다.

## 열화 경과일 보충

선택 조건 calendar_days [day]와 calendar_basis를 추가했습니다. 신호 time_s 및 사이클 수와 별개입니다. 근거가 없으면 공란으로 두며 RPT/순번을 일수로 치환하지 않습니다. 최신 팀 패키지의 LG M50LT에는 확인된 1,037개 측정의 경과일을 연결했습니다. 다른 자료는 확인되지 않은 값을 채우지 않았습니다.
