# 변환 검증 기록 항목

각 항목을 통과/실패/미검증/해당없음으로 기록하고 수치·로그를 연결한다.

- UTF-8 CSV, 필수 열, 숫자 파싱과 결측 표기 확인.
- 모든 신호 행의 네 식별자 존재, measurement_id=spectrum_id, 측정 내 ID 불변.
- measurements의 네 ID 조합 유일, 모든 신호 측정과 조건표 일대일 연결.
- cell_id의 cells 연결 및 고정 정보 복사 일치.
- manifest 파일 존재, 경로와 EIS/HPPC 열 구조 일치, 미사용 예시 제외.
- EIS 주파수 유한·양수 및 임피던스 유한, 부호·단위·극좌표 변환 원본 대조.
- HPPC 시간 유한·엄격 증가, 전류/전압 유한, 충전 양수 근거, 실제 휴지/펄스/회복 존재.
- 측정별 point_index=1..N, 원본/출력 행 수와 제외 개수 정합, 중복 원본 구간 검토.
- 조건의 단위·시점·근거 확인. SOC 범위, SOH의 기준, 온도 절대영도 이상, 사이클 비음수 정수, 용량 양수 확인. SOH>100은 근거 검토하며 임의 절삭 금지.
- 초기·현재 용량의 물리 셀 및 시험 조건 대조, 공칭/실측 분리, SOH 계산 재현.
- 원본 SHA-256 확인. 스크립트로 전수 수치 대조하고 변환별 최대 절대/상대 차이와 허용오차 기록. 표본만 확인했으면 표본 검증이라고 표시.
- 원본 변환본/조건 보충본 중복 집계 방지, 미확인 자료 별도 기록.
- 현재 도구에서 신호 읽기 및 조건표 연결 확인. 피팅 품질 통과와 구분해서 기록.
- raw 직접 입력과의 대조는 동일 측정 구간·설정으로 수행. 결과 차이는 신호·조건·설정 단계부터 추적.
