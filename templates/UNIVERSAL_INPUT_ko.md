# 더 유연해진 EIS·HPPC 입력

같은 물리량을 나타내는 열 이름과 명확한 단위라면 기존 템플릿의 철자와 완전히 같지 않아도 연결합니다. 셀의 화학계·모델명을 NCM 등 특정 종류로 제한하지 않습니다. 회로 식별 범위는 기존 EIS·HPPC입니다.

## 가장 간단하게 넣기

- EIS 1회: EIS/EIS_minimal_template.csv — 주파수·실수부·부호 있는 허수부, 3열.
- HPPC 시험 1개: HPPC/HPPC_minimal_template.csv — 시간·전류·전압, 3열.
- 기존 ID·조건 열을 포함한 모든 양식도 그대로 사용할 수 있습니다.
- 양식에는 열 이름과 빈 행만 있습니다. 실제 측정값을 채우고 사용하지 않은 빈 행은 삭제하세요.

## 지원 파일과 시트

CSV의 쉼표, 세미콜론, 탭을 표의 첫 줄 헤더 기준으로 구분합니다. 데이터 안의 긴 파일경로나 ID에서 구분자를 추정하지 않습니다. TSV·탭 TXT와 Excel XLSX/XLS도 읽습니다. Excel 시트가 여러 개면 앱에서 읽을 시트를 선택합니다. 조건표도 같은 형식으로 읽을 수 있습니다.

첫 줄은 열 이름, 아래부터는 같은 시점/주파수의 측정 행이어야 합니다. 제목·주석·장비 설정이 앞에 길게 붙은 원본, 머리글 없는 숫자 배열, 장비 전용 바이너리·MAT 구조체는 아직 자동 해석하지 않습니다.

유럽식 세미콜론 구분 + 소수점 쉼표 자료는 **상세 설정 → 단위·추가 정보 → 소수점**에서 쉼표를 고르고, **열 연결 · 원본 신호** 탭의 **입력형식 적용 · 다시 읽기**를 누르세요. 구분자를 직접 지정할 수도 있습니다. 숫자 표기의 의미가 모호할 때 소수점을 임의로 바꾸지 않습니다.

## 인식하는 대표 열 이름

| 뜻 | 예 |
| --- | --- |
| 주파수 | frequency_hz, Freq [kHz], f/Hz, 주파수 [Hz] |
| 실수부 | z_real_ohm, Re(Z) [mΩ], Z' (Ohm), 실수부 [Ω] |
| 부호 있는 허수부 | z_imag_ohm, Im(Z) [Ohm], Z'' (Ohm), 허수부 [Ω] |
| −Im | neg_im_z_ohm, -Im(Z) [mΩ], -Z'' (Ohm) |
| 크기·위상 | magnitude_ohm 또는 임피던스 절댓값 표기와 Phase (rad) |
| 시간 | time_s, Time [min], Test Time (s), 경과시간 [s] |
| 전류 | current_A, Current [mA], I [A], 전류 [A] |
| 전압 | voltage_V, Voltage [mV], U [V], 전압 [V] |
| SOC·SOH | soc_pct, SOC [%], SOC [fraction], SOH [%] |
| 온도 | temperature_C, Temperature [K], 온도 [C] |
| 측정 구분 | spectrum_id, Sweep ID, EIS ID, test_id, Measurement ID |

단위를 뺀 Current, Freq, Re(Z) 같은 이름은 물리량 후보로 연결할 수 있지만, 단위를 모르면 계산을 보류합니다. 단위·추가 정보에서 원본으로 확인한 단위를 지정하세요.

같은 뜻의 열이 2개 이상이면 자동으로 하나를 고르지 않습니다. **열 연결**에서 사용할 열을 직접 선택하세요. 같은 파일에 EIS와 시간 신호가 함께 있으면 자료 종류도 직접 선택해야 합니다.

## 단위 변환 범위

| 물리량 | 단위 |
| --- | --- |
| 주파수 | Hz, kHz, mHz, MHz |
| 임피던스 | Ω/Ohm, mΩ/mOhm, µΩ/uOhm, kΩ/kOhm, MΩ/MOhm |
| 시간 | ms, s, min, h |
| 전류 | µA/uA, mA, A |
| 전압 | µV/uV, mV, V |
| 위상 | deg/°, rad |
| 상태 | %/pct/percent, fraction/ratio/0-1 |
| 온도 | °C/C/degC/Celsius, K/Kelvin |

SI 접두어의 대소문자에 주의하세요. mHz와 MHz, mOhm과 MOhm은 다릅니다. 모호한 mhz 표기 등을 숫자의 크기로 추측하지 않습니다.

원본 표는 그대로 보존하고 내부 정규화 값과 변환 기록을 따로 둡니다. 단위 변환 외에 숫자를 보간·평활·채우거나 SOC·SOH를 자동 생성하지 않습니다.

## ID를 꼭 채워야 하는 경우

한 파일이 한 셀·한 측정/연속 시험이면 ID 열 없이 사용할 수 있습니다. 선택 ID 열 전체가 빈 경우에도 파일 단위 구분을 사용하며 물리 셀은 미지정으로 남깁니다. 하나의 ID 열에서 일부 행만 비어 있으면 해당 측정을 구분할 수 없으므로 보류합니다.

여러 셀·여러 EIS 스윕·시간이 재시작하는 여러 독립 시험은 반드시 ID로 구분하세요. 여러 스윕을 하나로 합치거나 시간 재시작을 임의로 잘라 새 시험으로 만들어 주지는 않습니다. EIS에 반복 주파수가 많거나 HPPC 시간 중복/역전이 있으면 측정 ID와 원본을 확인하세요.

조건표는 공통 ID로 연결합니다. 단순 행 순서로 연결하지 않고, 중복 키·서로 다른 조건이 충돌하면 요청을 표시합니다.

## 여전히 확인이 필요한 정보

HPPC의 전류 +가 충전인지 방전인지는 반드시 원 시험기 규약으로 확인하고 선택하세요. 전압 반응만 보고 추정하지 않습니다. 허수부는 원본의 Im 또는 −Im 정의에 맞춰 넣습니다.

필수 신호가 비어 있거나 숫자가 아니면 빈 행·소수점·열 연결을 확인하라는 요청을 표시합니다. SOC·온도·SOH 같은 선택 조건이 없으면 그 축만 제한되며, 신호가 충분할 경우 국소 피팅은 시도할 수 있습니다.

파일 호환성과 모델 적합도는 별개입니다. 입력을 읽는 기능을 넓힌 것이며, 모든 펄스 파형에서 파라미터를 보장하거나 일반 주행 데이터 자동 식별을 지원한다는 뜻은 아닙니다. HPPC의 충분한 휴지·펄스·회복과 EIS의 측정 대역은 계속 필요합니다.

## MATLAB 코드에서 사용

    o = uecm.defaults();
    o.CurrentSign = "charge_positive"; % 실제 시험 규약으로 확인한 경우에만 지정
    o.Sheet = "signals";
    o.MetadataSheet = "conditions";
    input = uecm.readInput("battery.xlsx", o, "battery.xlsx");
    prepared = uecm.prepare(input);
    disp(prepared.Requests);

텍스트의 소수점 쉼표는 o.DecimalSeparator=",", 구분자 수동 지정은 o.Delimiter=";" 또는 "tab"으로 설정합니다. 사용자 지정 단위·열 연결은 기존 Settings.Mapping과 단위 옵션을 계속 사용할 수 있습니다.
