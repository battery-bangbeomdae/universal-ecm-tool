배터리 ECM 도구 — 처음 쓰는 사람을 위한 사용법

간단한 주 화면

왼쪽 파일 추가로 자료를 열고, 데이터 종류와 HPPC 전류 부호를 확인한 뒤 피팅 실행를 누르세요. 가운데 표 아래에서 X·Y·Z축을 선택하면 오른쪽 3D 그래프가 바뀝니다. 부족한 정보는 아래 진단에 표시됩니다.

원본 표는 앞 500행 미리보기입니다. 피팅에는 읽을 수 있는 전체 측정 그룹을 사용합니다. ECM 결과의 다른 행을 누르면 왼쪽 모델별 RMSE 비교 대상이 바뀝니다. 결과 상세 · ECM 회로에서 피팅 과정·응답·회로를 보고, 상세 설정 · 열 연결에서 열 연결·단위·조건표·예제를 설정하세요. 상세 창을 닫아도 주 화면은 유지됩니다.

아래 기존 설명의 ‘내 CSV 파일 열기’는 현재 ‘파일 추가’, ‘ECM 계산’은 ‘피팅 실행’에 해당합니다. 상세 탭은 별도 창에 있습니다.

먼저 해 볼 일: 프로그램을 켜고 → ‘예제 열기’ → ‘④ ECM 계산’을 누르세요.

이 프로그램은 배터리 실험 기록에서 저항과 커패시턴스를 계산하고, 회로와 3D 그래프로 보여 줍니다. 계산한 값은 추정값입니다. 측정한 원본을 바꾸지 않습니다.

1. 프로그램 켜기

이 폴더를 통째로 보관해 주세요. +uecm 폴더를 지우거나 파일 하나만 다른 곳으로 옮기면 실행되지 않습니다.

지금 사용하는 Mac에서는 배터리_도구_시작.command를 두 번 클릭하세요. MATLAB이 열리고 프로그램이 나타납니다. 이 실행기는 /Applications에 설치된 MATLAB을 사용합니다.

MATLAB이 이미 켜져 있다면 다음 방법도 됩니다.

1. MATLAB에서 이 폴더의 START.m 파일을 엽니다.

2. 위쪽의 초록색 Run / 실행 버튼을 누릅니다.

3. Universal ECM Tool 창이 나타나면 준비 완료입니다.

이 도구는 MATLAB 안에서 실행하는 프로그램입니다. MATLAB 없이 실행하는 독립 앱은 아닙니다. 현재 Mac의 MATLAB R2026b에서 실행·검증했습니다. 다른 버전·컴퓨터는 별도 확인이 필요합니다.

이번 버전: 1RC와 2RC를 비교해 보기

같은 자료 → 계산 과정 → 그래프 비교 → 회로 보기를 차례대로 따라 하면 됩니다.

1. 왼쪽 예제에서 ‘가상 2RC HPPC · 비교 연습’을 고르고 ‘예제 열기 → ④ ECM 계산’을 누릅니다.

2. ‘② 피팅 과정’이 열립니다. 계산하면서 오차가 어떻게 줄었는지 실제 기록을 봅니다. 서로 다른 초기값으로 여러 번 시도한 결과도 있습니다.

3. ‘③ 1RC·2RC 비교’를 누릅니다. 실측 역할의 가상 자료와 두 모델 선을 한 그림에 겹쳐 봅니다. 아래 잔차는 ‘자료 − 모델’의 차이입니다.

4. 표의 RMSE가 작을수록 지금 넣은 자료를 더 가깝게 따라갑니다. MAE는 평균 차이, MaxAbsError는 가장 큰 차이입니다. 숫자 옆 단위도 확인하세요.

5. 위의 ‘자세히 볼 모델’에서 1RC 또는 2RC를 고르고 ‘선택 모델의 ECM 보기’를 누릅니다. ‘④ ECM 회로’에서 회로 그림과 숫자를 봅니다.

6. ‘3D 그래프’에서는 모델 선택을 ‘1RC’ 또는 ‘2RC’로 바꾸고 X/Y/Z를 고릅니다. 2RC의 두 번째 가지는 R2_Ohm / C2_F / tau2_s입니다.

1RC는 저항·커패시터 묶음 하나로, 2RC는 묶음 두 개로 반응을 설명합니다. 2RC가 항상 더 좋은 것은 아닙니다. 오차가 아주 조금 줄어도 두 묶음을 구분할 정보가 부족할 수 있습니다. 그래서 ‘오차가 가장 작은 모델’과 ‘권장 모델’을 따로 보여 줍니다. 새 시험 자료가 없으면 새 자료에서도 더 잘 맞는지는 아직 모릅니다.

이 사진의 예제는 가상 자료입니다. 실험 결과로 쓰면 안 됩니다. 실제 자료의 비교 결과는 [비교 결과 설명](docs/MODEL_COMPARISON_RESULTS_v02_ko.md)에 따로 정리했습니다.

2. 가장 쉬운 첫 연습

처음부터 내 파일을 넣지 않아도 됩니다.

1. 왼쪽 맨 위에서 ‘실제 EIS · 공개 자료 12개’를 고릅니다.

2. ‘예제 열기’를 누릅니다. 이 예제는 공개 실험 자료의 일부입니다.

3. ‘④ ECM 계산’을 누릅니다.

4. 계산이 끝나면 위쪽 ‘3D 그래프’ 탭을 누릅니다.

5. X는 남은 충전량 SOC, Y는 온도, Z는 Rs_Ohm처럼 고릅니다.

6. Z를 Rct_Ohm 또는 Ceff_F 등 실제 계산된 항목으로 바꿔 봅니다.

7. 그래프의 점 하나를 누르면 그 측정의 회로와 측정값/모델 비교가 나옵니다. ECM 결과 표의 줄을 눌러도 됩니다.

회로에 따라 Cdl 대신 Ceff가 나올 수 있습니다. 서로 다른 정의의 값이어서 이름을 바꿔 표시하지 않습니다.

3. HPPC도 연습해 보기

HPPC는 전류를 잠깐 흘렸을 때 전압이 어떻게 변하는지 기록한 시험입니다.

1. 왼쪽 위에서 ‘가상 HPPC · 화면 연습’을 고릅니다.

2. ‘예제 열기’ → ‘④ ECM 계산’을 누릅니다.

3. Z에서 R0_Ohm, R1_Ohm, C1_F, tau_s를 바꿔 봅니다.

4. 점이나 결과 표의 줄을 누르면 실측 역할의 연습 전압과 모델 전압을 비교할 수 있습니다.

‘가상’은 화면과 계산을 시험하려고 만든 자료입니다. 실제 배터리 실험 결과로 쓰면 안 됩니다. 이 예제의 회로 정답은 별도로 계산해 프로그램 검사에 사용했습니다. 실제 HPPC 자료를 넣으면 정확도가 같다고 보장하는 것은 아닙니다.

추가로 ‘실제 HPPC · 주의 사례 1개’도 들어 있습니다. 실제 측정이지만 이 단순 회로로 충분히 설명되지 않아 ‘주의’가 표시됩니다. SOC도 없어 SOC축은 보류됩니다. 이는 실패를 숨기지 않고 알려 주는 연습 사례입니다. ‘ECM 결과’와 ‘데이터·추가 요청’에서 이유를 읽고, 그 값을 바로 연구 결과로 쓰지 마세요.

4. 내 파일 넣기

파일은 우선 CSV로 준비하세요. Excel에서 ‘다른 이름으로 저장 → CSV’로 만들 수 있습니다. 원래 파일은 따로 남겨 두세요. 기기마다 다른 TXT를 모두 자동으로 읽는 기능은 아직 없습니다.

1. ‘내 CSV 파일 열기’를 누르고 파일을 고릅니다.

2. ‘데이터·추가 요청’ 탭에서 열 연결을 확인합니다.

3. 왼쪽은 자료의 뜻, 오른쪽은 내 파일의 열 이름입니다. 다른 이름이 연결되었다면 오른쪽 칸을 눌러 바꿉니다.

4. ‘단위·추가 정보’ 탭에서 원래 파일의 단위를 확인합니다. 모르는 단위를 추측해서 넣지 마세요.

5. HPPC에서는 왼쪽 ‘전류의 +가 뜻하는 것’을 골라 주세요. 시험기의 설명을 보고 방전 때 +인지 충전 때 +인지 확인합니다.

6. ‘③ 자료 확인’을 누릅니다. 요청이 있으면 안내를 보고 부족한 자료를 넣습니다.

7. 계산할 수 있는 상태면 ‘④ ECM 계산’을 누릅니다.

열은 표에서 위아래로 이어진 한 종류의 자료입니다. 예를 들어 시간 열, 전류 열, 전압 열이 따로 있습니다.

6. 3D 그래프 읽기

- X와 Y: 내가 비교할 두 조건입니다. 예: 남은 충전량과 온도.

- Z: 계산한 회로 파라미터입니다. 예: 저항 R0.

- 점 하나: 측정 스펙트럼 또는 펄스 하나에서 구한 추정 결과입니다. 점 하나가 곧 배터리 하나라는 뜻은 아닙니다.

- 빈 곳: 자료가 없거나 비교 조건이 맞지 않는 곳입니다. 프로그램이 값을 채워 넣지 않습니다.

- ‘후보만’: 기본 검사를 통과한 결과만 봅니다. 독립 시험 검증까지 끝났다는 뜻은 아닙니다.

- ‘모두 (주의 포함)’: 검토가 필요한 결과도 함께 봅니다. 연구 결과로 쓰기 전에 이유와 응답을 확인하세요.

면으로 보고 싶으면 그룹에서 같은 셀·방법·회로를 고르고 ‘조건 맞으면 면 연결’을 체크합니다. 두 축이 충분히 변하지 않거나 반복값·조건 차이·큰 빈 구간이 있으면 면 대신 점을 보여 줍니다. 면은 관측점에서 구한 추정값을 연결한 표시입니다.

HPPC의 R1/C1과 EIS의 Rct/Cdl은 같은 이름으로 바꿔 쓰지 마세요. Ohm은 저항, F는 커패시턴스, s는 시간의 단위입니다.

3. 그 안에 UniversalECM_날짜_시간이라는 새 폴더가 만들어집니다.

4. 다음에 이어서 보려면 ‘저장한 결과 다시 열기’를 누르고 그 폴더의 session.mat을 고릅니다.

8. 지금 할 수 있는 것과 아직 못 하는 것

현재 첫 버전은 CSV/TSV 표, EIS의 RC/Zarc 회로 후보, HPPC의 국소 1RC·2RC 비교, 자료 요청, 조건표 연결, 축 선택, 점·조건부 면, 원본/모델 비교, 저장·다시 열기를 지원합니다.

일반 주행 데이터 자동 식별, 모든 기기 파일 형식, 모든 화학계에서의 정확도 보장은 아직 지원하지 않습니다. 이 프로그램의 ‘범용’ 목표는 자료에 맞게 분석 경로를 선택하고, 할 수 없는 부분은 정확히 안내하면서 지원 범위를 넓혀 가는 것입니다. 실제 HPPC 주의 사례의 비교는 수행했지만, 별도 시험에 대한 예측 검증과 새로운 셀 계열 검증은 추가로 필요합니다.

문제가 생기면 아래쪽 상태 메시지와 ‘데이터·추가 요청’ 화면의 문구를 알려 주세요. 실제 자료의 빈칸을 예제 숫자로 채우면 안 됩니다.

이전 버전의 창이 열려 있다면 닫고 새 실행기로 다시 켜 주세요. 창 제목은 Universal ECM Tool | 셀 데이터 · ECM입니다.

2D·3D / Simulink 보기

그래프 위 2D·3D 선택으로 전환합니다. 2D에서는 X조건과 Y축 ECM 값을 고릅니다. 3D에서 ‘마우스 회전’을 켜고 드래그하면 회전하며, 기본·정면·측면·위 버튼도 사용할 수 있습니다. 점 선택은 회전을 끈 뒤 사용하세요.

결과 상세에서 1RC 또는 2RC를 선택하고 ‘Simulink로 열기’를 누르면 선택한 추정값이 적용된 새 모델이 열립니다. 임시 모델이므로 보관하려면 다른 이름으로 저장하세요. Simulink 신호 블록 모델이며 Simscape 물리 회로는 아닙니다. 전류(방전 +)와 Ubase를 외부 입력으로 받습니다. EIS에서 OCV를 생성하지 않으며, HPPC의 Ubase는 국소 기준전압입니다. CPE/ZarcL은 현재 지원하지 않습니다.

다양한 입력 형식

CSV·세미콜론·탭·Excel(XLSX/XLS), 다양한 열 이름과 명시적인 단위를 지원합니다. Excel 시트가 여러 개면 선택하세요. 소수점·구분자를 바꾼 뒤 상세 창에서 입력형식 적용 · 다시 읽기를 누르세요. 범용 입력 안내를 확인하세요.
