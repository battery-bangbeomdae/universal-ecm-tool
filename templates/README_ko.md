# ECM 입력 템플릿

**입력 범용화 업데이트:** [다양한 열 이름·단위·Excel/구분자 사용법](UNIVERSAL_INPUT_ko.md). 최소 3열 양식도 추가했습니다. 기존 양식은 그대로 사용할 수 있습니다.

**2026-11-06 전수 검증:** 검증 결과(과거 검증 산출물은 정리 시 삭제)를 확인하세요. 읽기 성공과 ECM 품질 통과는 다릅니다. Wuppertal HPPC는 현재 검출 조건에서 23구간 모두 결과가 없으며, 다른 자료도 review를 구분해야 합니다. CSV 읽기와 HPPC 화면 갱신 문제를 수정했으므로 앱을 다시 실행하세요.

**실제 데이터를 이미 채운 파일:** [filled_real_data/ 사용법과 목록](filled_real_data/README_ko.md). EIS 3개, HPPC 7개이며 아래 빈 양식과 별도로 보관합니다.

데이터 종류에 맞는 폴더를 사용하세요.

- [EIS 사용법](EIS/README_ko.md): 주파수·임피던스 측정. 원본 표기에 따라 Im, −Im, 크기·위상 중 하나를 고릅니다.
- [HPPC 사용법](HPPC/README_ko.md): 시간·전류·전압의 휴지·펄스·회복 측정.

각 CSV는 **첫 줄 열 이름 + 빈 입력 행 20개**입니다. 가상 숫자나 피팅값은 넣지 않았습니다. 파일을 복사하여 실제 측정값만 채우고 UTF-8 CSV로 저장하세요. 필요한 만큼 행을 늘리고, 사용하지 않은 빈 행은 삭제하세요. 원본은 별도로 보관하세요.

모르는 SOC·온도·SOH 등은 빈칸으로 두세요. 유지한 식별자 열은 각 측정 행에 채워야 합니다. 한 셀·한 시험이고 쓰지 않는 식별자가 있다면 해당 열 전체를 삭제할 수 있습니다. 여러 셀·여러 시험·반복 EIS는 반드시 서로 구분하세요.

앱 실행 파일은 `ECM/Universal_ECM_Tool/START.m`입니다. **파일 추가 → 데이터 종류/전류 부호 확인 → 필요하면 상세 설정 · 열 연결 → 피팅** 순서입니다. 입력 부족 안내는 주 화면 아래 진단에 표시됩니다. 이미 정리된 실측 파일은 `ECM/gh/data/model_input/EIS/`, `ECM/gh/data/model_input/HPPC/`에 있어 다시 양식에 옮길 필요가 없습니다.
